# Гранд сводка ИД

Веб-приложение для совместной работы над исходными данными проточных частей турбин.

## Сборка exe

```powershell
py -3 compile.py
```

Готовый файл: `dist\GrandSummary\GrandSummary.exe`. Рядом появится папка `data` с базой после первого запуска. Папку `dist\GrandSummary` можно копировать целиком.

## PyCharm на новом компьютере

1. Откройте папку проекта.
2. Settings → Python Interpreter → Add Interpreter → Virtualenv: расположение `.venv` в корне проекта, базовый Python 3.12.
3. Запустите конфигурацию **«Гранд сводка»** (зелёный треугольник).

При первом запуске программа сама ставит пакеты из `requirements.txt` в выбранный интерпретатор и при необходимости собирает интерфейс (`npm install` / `npm run build`). Повторные запуски это пропускают.

Конфигурации в репозитории:

- **Гранд сводка** — окно Windows (`run_desktop.py`)
- **Гранд сводка API** — сервер для браузера (`run_web.py`, порт 8000)
- **Гранд сводка тесты** — `pytest tests`

Нужны сеть (первый `pip` / `npm`) и Node.js, если ещё нет `frontend/dist`.

## Запуск как программа (окно Windows)

```powershell
py -3 run_desktop.py
```

Зависимости ставятся сами при запуске. Вручную то же самое:

```powershell
py -3 -m pip install -r requirements.txt
cd frontend
npm install
npm run build
```

Откроется окно «Гранд сводка ИД». Браузер и второй терминал не нужны. Закрытие окна завершает программу.

## Запуск в браузере (разработка)

Конфигурация PyCharm **«Гранд сводка API»** или:

```powershell
py -3 run_web.py
```

Либо вручную:

```powershell
py -3 -m uvicorn backend.main:app --reload --port 8000
```

В другом терминале:

```powershell
cd frontend
npm run dev
```

Откройте http://127.0.0.1:5173 — фронт проксирует `/api` на порт 8000.

Имя пользователя Windows подставляется автоматически.

## Настройки

- `GRAND_SUMMARY_DB` — путь к SQLite или URL (`sqlite:///...`, `postgresql://user:pass@host/db`). По умолчанию `data/grand_summary.db`.
- `GRAND_SUMMARY_ACL` — JSON с списками `editors` / `readers`. По умолчанию `data/acl.json` (`"editors": ["*"]`).
- `templates/rules.json` — справочники и правила унификации.
- `templates/triangle_mapping.json` — подписи файла тепловиков → ключи каталога.

## Вкладки

1. **Объект и треугольники** — выбор объекта, импорт Excel тепловиков.
2. **Таблица ИД** — шаблон `ТЗ/default.XLS`, режимы просмотра и редактирования, жёлтый черновик, зелёное сохранение с комментарием, кнопка «Редактировать структуру».
3. **Отчёт** — служебная записка Word с подсветкой изменений.

В меню «Справка»: инструкция, журнал изменений приложения (поиск и дерево версий) и журнал изменений пользователей (таблица / лента).
