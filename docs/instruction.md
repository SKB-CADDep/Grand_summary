# Инструкция. Гранд сводка ИД

1. ЗАПУСК

1.1. Как программа: в PyCharm конфигурация «Гранд сводка» или `py -3 run_desktop.py`. На новом компьютере первый запуск сам ставит пакеты из `requirements.txt` в интерпретатор PyCharm. Готовый файл: `dist\GrandSummary\GrandSummary.exe` (сборка: `py -3 compile.py`).
1.2. В браузере для разработки: конфигурация «Гранд сводка API» (`run_web.py`, порт 8000) и `npm run dev`, затем http://127.0.0.1:5173.
1.3. Имя пользователя Windows подставляется автоматически.
1.4. Права задаются в `data/acl.json`: `editors` — отдел ОР (запись), `readers` — просмотр. Значение `"*"` разрешает всем. Переменная `GRAND_SUMMARY_ACL` указывает другой файл.

2. ВКЛАДКА «ОБЪЕКТ И ТРЕУГОЛЬНИКИ»

2.1. Выберите объект. Без объекта таблица и отчёт недоступны.
2.2. Если по объекту уже есть сводка, появится предупреждение «работа уже начата».
2.3. При необходимости создайте объект вручную или загрузите список из Excel (колонки: наименование, станция, турбина, цилиндр, external_id).
2.4. «Синхронизировать объекты» обновляет список из `data/objects.json` по `external_id` (заглушка будущей связи с программой объектов / Task Tracker).
2.5. Кнопка «Импортировать из Excel» загружает файл треугольников от тепловиков. Значения попадают в ячейки шаблона по подписи параметра и номеру ступени. Соответствие подписей — `templates/triangle_mapping.json`. Импорт создаёт версию 0 «Считывание треугольников».
2.6. «Добавить ступень» добавляет колонку в текущую сводку.

3. ВКЛАДКА «ТАБЛИЦА ИД»

3.1. Таблица повторяет шаблон default.XLS: параметры в строках, ступени и КУ в колонках.
3.2. Таблица открывается в режиме просмотра: клик по ячейке выделяет строку и столбец и показывает историю, но не предлагает ввод. «Режим редактирования» включает правку в самой ячейке. Выделение строки и столбца бледнее рамки выбранной ячейки. Изменение без комментария делает ячейку жёлтой (черновик) и в историю не пишется.
3.3. «Сохранить значение» требует комментарий-причину. После сохранения ячейка зелёная, в истории: автор, дата, старое/новое значение, комментарий.
3.4. «Отменить черновик» возвращает ячейку к последнему сохранённому значению.
3.5. Клик по ячейке открывает историю.
3.6. В поле «Ссылка» можно вписать URL (чертёж, документ). В таблице и в Word ссылка прячется в значении ячейки; комментарий в исходящий документ не попадает.
3.7. Для типа исполнения и материалов открывается справочник. Правило «Венцовая диафрагма» копирует материал лопатки в материал тела и блокирует оба поля. Правило «ЦФБ с позиционированным бандажом» копирует материал лопатки в материал бандажа и блокирует бандаж.
3.8. «Редактировать структуру» включает правку наименований, единиц и уровня вложенности. Можно добавить строку рядом, вложенную строку или группу (уровень 0) и удалить выбранную. Меняется только текущая сводка, каталог default.XLS не трогается.
3.9. Жёлтых ячеек при уходе со страницы быть не должно: система покажет список несохранённых — сохраните с комментарием или отмените черновик.
3.10. Если ячейку уже изменил другой пользователь, запись отклоняется (конфликт). Обновите таблицу и повторите.
3.11. Отменить (Ctrl+Z) и повторить (Ctrl+Y) в шапке окна действуют только на шаги этой сессии, в том порядке, в каком вы их сделали — как в Word. После закрытия программы стек пустой.
3.12. Стрелки на клавиатуре переводят выделение на соседнюю ячейку. В режиме редактирования влево/вправо сначала двигают курсор в тексте, а с края ячейки переходят к следующей.

4. ВКЛАДКА «ОТЧЁТ»

4.1. Выберите тип: короткая служебка или полная сводка.
4.2. Выберите версию, относительно которой подсвечивать изменения.
4.3. «Создать сводку» формирует Word. Комментарии в исходящий документ не попадают. Создаётся снимок версии. Гиперссылки ячеек сохраняются.

5. ОБУЧЕНИЕ

5.1. Кнопка «?» в меню или пункт «Справка → Обучение» запускает короткий тур с подсветкой элементов.
5.2. Два сценария: обзор вкладок и объекта; работа с таблицей и отчётом. «Далее» / «Назад» / «Пропустить обучение».
5.3. При первом запуске нового пользователя программа обязательно предложит обучение. После этого оно открывается только кнопкой «?» или пунктом «Справка → Обучение».

6. УВЕДОМЛЕНИЯ

6.1. Если значение подтвердил другой автор, предыдущему автору приходит уведомление в меню «Уведомления».

7. ЖУРНАЛЫ

7.1. «Справка → Журнал изменений приложения»: поиск по тексту, группировка по дате или по действиям, слева дерево версий, справа описание выбранного выпуска.
7.2. «Справка → Журнал изменений пользователей»: кто, когда и что менял (ячейки, параметры, импорт, версии, сводки). Виды «Таблица» и «Лента», фильтры «Показать» и «Поле».

8. ЦВЕТА

- Жёлтый — несохранённое изменение или отличие от выбранной версии в отчёте.
- Зелёный — зафиксированное значение / новое значение в отчёте.
- Серый — заголовок группы параметров или поле, заблокированное правилом.
